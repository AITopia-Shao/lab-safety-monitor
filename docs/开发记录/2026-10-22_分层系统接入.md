# 2026-10-22 分层视觉系统接入

把“实验楼母系统 → 多个实验室 → 每实验室一个宏观、多个微观实验台”的升级接入仓库当前版本。默认示例为两间实验室、三个实验台、五路模拟视觉通道。

原有桌面、小屏、Web、安全助手、温度预测、固件和 R1–R9 安全核心保留。分层视图通过 `python run_app.py --hierarchy` 单独运行；根目录 Mac 一键入口默认打开这个视图，原单实验室模式仍可独立启动。

新增能力：独立微观模型/视频源与温湿度配置、多节点预览、楼宇事件路由、可配置目标与动作、跨实验室报警/断电请求、指令去重、执行结果、人工确认、事件恢复与独占运行目录。

与当前仓库的适配：

- 拓扑和状态目录位置定义在 `src/config.py` 默认值及 `config.yaml` 中，通过 `cfg()` 读取。
- 分层事件由主入口同步到统一事件中心 `events.log()`；JSON 状态与 JSONL 保留楼宇指令恢复、证据与审计，不建立第二个数据库。
- 真实断电复用既有 SerialComm CRC16 + SEQ + ACK 协议，每个目标指定明确串口，不自动扫描到其他实验室。没有复制早期五字节原型协议。
- 模拟来源事件不得调用真实执行器。配置真实执行器的实验室禁止混入模拟视觉/温湿度。人工确认与模拟记录清理不恢复供电。
- Mac 使用独立依赖文件，环境、缓存、启动日志、数据库和演示视频均不提交。
