
一、 作品概述与立项背景

高校及科研院所的化学、生物实验室常发生由于人员违规操作、防护缺失、擅自离岗导致的
火灾、爆燃及人员伤亡事故。针对传统监控“事后调录像追责、单目视觉视野局限、软件警报
与硬件强电切断断层”的三大痛点，本团队自主研发了《基于双摄协同的实验室安全事前干预
监测系统》。

系统核心特色与技术创新点：
1. 【双核驱动·宏微协同感知】：
   宏观通道采用轻量化 YOLOv8 模型，毫秒级检测人员防护规范（口罩/实验服）、违规饮食，
   并通过人体几何中心 Y 轴追踪研判人员伏案昏厥/异常睡眠，维持 5 秒无人值守滑动计时；
   微观通道聚焦实验台面，高精度检测烧杯、试管、酒精灯等加热容器。
2. 【跨模态边缘决策状态机】：
   将视觉语义与现场 USB 工业温湿度传感器物理遥测多维融合，当判定“微观加热设备 + 
   宏观无人值守 + 实时温度 > 55℃”时，立即触发 CRITICAL 高危警报。
3. 【硬件真闭环·毫秒级强电切断】：
   通过下位机 STM32 定制 115200 波特率定长 Hex 校验协议（0xAA..0x55），结合 3 秒
   防抖防电弧保护机制，实现对实验台总电源的物理级硬切断。
4. 【水色海浪新粗野美学 UI 与专家评审流水线】：
   独创“Water-Blue Pixel Brutalism”治愈系界面，底层手写数学正弦流动海浪、纯黑硬阴影
   与机械按键塌陷物理反馈；内置现场“专家评审流水线”，支持评委对抓拍卡片现场核验并
   实时累积 35 分满分计分板，极大提升路演互动观感！

三、 快速上手与运行指南

1. 源码直接运行：
   $ pip install -r requirements.txt
   $ python run_app.py

2. 运行已编译的可执行程序 (Linux)：
   $ cd 02_源码与可执行程序/bin/linux/LabSafetyMonitor/
   $ ./LabSafetyMonitor

3. 启动环境仿真控制器 (用于离线路演/测试干烧断电)：
   $ python 02_源码与可执行程序/env_controller.py

4. 在 Windows 系统上一键编译：
   将 02_源码与可执行程序/ 拷贝至 Windows 环境，双击运行 build_windows.bat 即可。
