### 1.3 判定规则一览

| 规则 | 条件 | 动作 |
|---|---|---|
| 未戴护目镜、未穿实验服、未戴手套、未戴口罩、未戴头罩 | 3 秒窗口内命中率 ≥ 60% | 语音 + 黄灯 + 截图（提醒） |
| 实验区饮食 | 同上 | 语音 + 黄灯 + 截图（警告） |
| 疑似伏案 | 面部装备框中心低于 60% 画面高度，且 10 秒内几乎不动 | 语音 + 黄灯 |
| 器皿靠近桌边 | 器皿底边中心到桌边线的距离 < 0.06 | 语音 + 黄灯 |
| 加热中无人值守 | 热源 ≥ 50℃ 且无人 | 警告，倒计时 60 秒后断电 |
| 干烧 | 热源 ≥ 120℃ | **断电锁定**（下位机 150℃ 本地兜底） |
| 升温异常 | 升温 ≥ 2℃/s 且 ≥ 80℃ | 警告 |
| 烟雾 | MQ-2 ≥ 1800（下位机本地 2500） | **断电锁定** |
| 高湿 / 环境高温 | > 80% / > 40℃ | 警告 |
| 兜底（未接红外测温） | 可加热器皿 + 无人 + 环境 > 55℃ | **断电锁定** |
| 上位机失联 | 下位机 30 秒收不到心跳，且仍在加热 | 下位机自主断电 |

## 2. 香橙派部署步骤

1. **烧录系统**：从 orangepi.cn 下载 Orange Pi 5 的 **Ubuntu 22.04 Desktop** 镜像，用 balenaEtcher 写入 TF 卡。
2. **拷贝项目**：把 `labguard` 整个文件夹拷到香橙派上（例如 `~/labguard`）。
3. **转换模型（在 PC 上做）**：在 WSL2（Ubuntu）里执行
   `pip install "ultralytics>=8.3.0" rknn-toolkit2`，然后 `python tools/export_rknn.py`。
   把生成的 `models/*_rknn_model/` 两个文件夹拷到香橙派的 `models/` 下。
4. **一键部署**：`bash deploy/orangepi/setup.sh`，完成后重新登录。
5. **配置摄像头**：`ls -l /dev/v4l/by-id/`，把两个摄像头的路径分别填进 `config.yaml` 的 `camera.pano` 和 `camera.desk`。
6. **标定桌边线**：打开程序，看台面画面里那条黄色细线，修改 `desk.edge_line`，让它和靠近操作者的那条桌边重合。
7. **联调下位机**：`python tools/serial_probe.py` 应该能看到实时温湿度和热源温度；加上 `--cut` 可以测试断电和 ACK。
8. **启动**：`bash deploy/orangepi/start.sh`；重启后会自动启动。

## 3. 下位机接线（ESP32-S3-DevKitC-1）

```
ESP32-S3            外设
3V3 / GND ───────── SHT30、MLX90614 的 VCC / GND（两者都挂在同一组 I2C 上）
GPIO8  (SDA) ────── SHT30 SDA、MLX90614 SDA
GPIO9  (SCL) ────── SHT30 SCL、MLX90614 SCL
GPIO1  (ADC) ────── MQ-2 AO（MQ-2 用 5V 供电；AO 经 10kΩ/20kΩ 分压后再接 GPIO1）
GPIO10 ──────────── 继电器模块 IN（模块 VCC 接 5V）
GPIO11/12/13 ───── 红 / 黄 / 绿 LED（各串 220Ω 电阻到 GND）
GPIO14 ──────────── 1kΩ → S8050 基极；集电极接有源蜂鸣器负极；蜂鸣器正极接 5V
GPIO4  ──────────── 复位按钮另一端接 GND（内部上拉）
GPIO17 (TX) ─────── 1kΩ → DFPlayer RX
GPIO18 (RX) ─────── DFPlayer TX；DFPlayer 的 SPK1/SPK2 接喇叭，VCC 接 5V
UART 口 (Type-C) ── 香橙派 USB（供电 + 通信）

继电器 COM / NO ─── 串入 12V 加热片的 + 极回路（一定接常开 NO）
MLX90614 ────────── 对准加热片表面，距离 2~5 cm
```

**固件烧录**：Arduino IDE → 开发板选 "ESP32S3 Dev Module" → 安装 3 个库（Adafruit SHT31、Adafruit MLX90614、DFRobotDFPlayerMini）→ 打开 `firmware/lab_guard_esp32/lab_guard_esp32.ino` → 上传。
**语音文件**：`pip install edge-tts` 后运行 `python tools/gen_voice.py`，把生成的 `voice_sd/mp3` 文件夹拷到 TF 卡根目录。

### 现场演示脚本（约 4 分钟）
1. 穿戴整齐入场：绿灯亮。
2. 摘下护目镜：约 3 秒后语音"请佩戴护目镜"，黄灯亮，事件入库。
3. 把烧杯推到桌边：触发"器皿靠近台面边缘"提醒。
4. 打开加热片，人离开：日志出现"加热中无人值守，XX 秒后自动断电"（演示时可以把 `unattended_heating_cut_s` 改成 20）。
5. 倒计时结束：继电器断开，红灯亮，蜂鸣器响，日志显示"下位机已确认断电"。
6. **拔掉香橙派的 USB 线，再加热**：下位机看门狗 30 秒后自主断电。这是证明"安全不依赖上位机"的高光时刻。
7. 现场长按复位键恢复供电，展示事件库截图。
