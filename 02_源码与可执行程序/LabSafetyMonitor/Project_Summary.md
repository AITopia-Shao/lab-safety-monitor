# 基于双摄协同的实验室安全事前干预监测系统

### 1. 核心架构设计 (双核驱动 + 并发处理)
整个系统采用了标准的 **生产者-消费者 (Producer-Consumer) 架构**，彻底将“耗时的 AI 深度学习运算”与“流畅的 UI 界面渲染”隔离开来。

*   **生产者 (Producer)**：负责不断从双路摄像头（或您导入的 mp4 媒体流）中拉取画面。我们将两路画面拼接打包放入高速内存队列，即使摄像头卡顿，也不会影响后续计算。
*   **消费者 (Consumer)**：负责从队列中取出画面，并同时送入两个您自己训练的 YOLO 模型。
    *   **Model A (PPE/行为)**：运行在全景监控画面上，负责识别“未戴口罩”、“未穿实验服”、“饮食 (Eating/Drinking)”，并且内置了几何中心判定算法，用于检测人体 Y 轴判断是否在“伏案/睡觉”，以及 5 秒计时判断“无人值守”。
    *   **Model B (Chem 容器)**：运行在桌面微观画面上，精准识别烧杯、试管等化学实验容器。
*   **通信与分离**：后端的 `DualInferenceSystem` 运行在 `InferenceThread` (QThread) 子线程中，通过 Qt 的 Signal 信号安全地将处理完的带框画面、报警信号传回给主 UI，从而保证 UI 拥有 60FPS 的丝滑体验。

### 2. 交互界面设计 (水色海浪像素粗野风)
在您的指导下，我们抛弃了传统的黑白灰工业 UI，独创了这套极具比赛辨识度的 **Water-Blue Pixel Brutalism** 界面：

*   **温柔水色基调**：主色调使用马卡龙浅蓝 (`#E1F5FE`) 与柔和靛蓝 (`#5C6BC0`)，极大程度降低了传统监控软件的压迫感。
*   **手写底层动态海浪**：放弃了静态背景，我们重写了 `WaveBackgroundWidget` 的底层 `paintEvent`，利用数学正弦波 (Sine Wave) 在背景绘制了两层持续流动的半透明海浪动画，治愈感拉满。
*   **真·物理机械按键交互**：所有的单选、复选控制全部改为了“带粗边框与实心硬阴影”的像素方块按钮。并且在 CSS 中加入了精确的 margin 偏移，使得每次鼠标按下，都会产生极其真实的“按钮被按下塌陷”的物理动画反馈。
*   **纯正像素字体注入**：系统启动时会静默从云端拉取 `Zpix` 字体进行强制全局渲染，带来如同 GBA 掌机时代的复古街机感。

### 3. 赛题核心：专家评审评分机制
针对比赛要求，我们在界面右侧打造了独特的**异常事件评审流水线**：
*   当左侧 AI 捕捉到真实的“未戴护目镜”或“吃东西”等危险动作时，系统会自动将当时的双路画面截屏，并生成一张带有粗边框和阴影的“报警卡片”推送到右侧的流动列表中。
*   卡片底部自带 `[ ✅ 正确 ]` 和 `[ ❌ 误报 ]` 的像素机械按钮。
*   评委点击验证正确后，右下角的 **TOTAL SCORE** 计分板会自动为您累加 1.75 分（严格限制满分 35 分）。这种互动设计能让评委直接参与到您的系统测算中，极大提升路演观感！

### 4. 离线媒体与回放控制
为了方便您脱离真实摄像头进行赛前演示与测试，我们在面板左下方加入了媒体重载功能：
*   支持随时导入本地准备好的 `.mp4` 录像。
*   提供无缝的 **暂停 (⏸)** 与 **进度条拖拽跳转** 功能。拖拽时底层会通过 OpenCV 的 `CAP_PROP_POS_FRAMES` 瞬间重定位视频帧，不会引起任何崩溃。

## 🛠️ 文件结构清单

*   `src/hardware/sensor_worker.py`: 工业级 USB 温湿度传感器采集后台线程，具备真实串口 ASCII 读取与离线自动平滑模拟降级机制。
*   `src/core/state_machine.py`: 跨模态边缘状态机联合决策逻辑，具备高温干烧联动与高湿受潮告警，实现继电器断电闭环。
*   `src/ui/main_window.py`: 工业新粗野主义风格环境遥测面板 (`TelemetryCard`) 与主监控界面。
*   `LabSafetyMonitor/main_gui.py`: 系统主入口兼容层，打通 `src` 模块并提供向后兼容。
*   `LabSafetyMonitor/dual_inference.py`: 系统的“大脑”，包含双摄 YOLO 推理及状态判定。
*   `LabSafetyMonitor/serial_comm.py`: 下位机硬件串口通信模块，支持继电器断电指令 `send_power_off()`。
*   `requirements.txt`: 依赖清单，包含 `pyserial>=3.5`、`PySide6>=6.5.0` 等。
